Product goal
A personal warranty manager where users can add warranty information using normal text or an image, store it securely, receive expiry reminders, and find warranty information using natural-language queries.

MVP features
Authentication
- Register
- Login
- Logout
- Protected routes

Warranty management
- Add warranty manually
- Add warranty using natural-language text
- Add warranty using image
- Edit warranty
- Delete warranty
- View warranty details

Dashboard
- Total products
- Active warranties
- Expiring warranties
- Top 5 nearest-expiring warranties
- "What needs my attention?"

Search / AI query
Examples:
Which warranties expire next month?

Show my electronics warranties.

When does my Samsung TV warranty expire?

Which products are currently under warranty?
